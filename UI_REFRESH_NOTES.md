# BookVerse UI Refresh

This version replaces the previous gradient-heavy visual style with a clean app-first dark interface.

## Visual direction
- No LinearGradient or RadialGradient widgets in `lib/`.
- Near-black background and layered dark surfaces.
- One red accent for primary actions, selected states and prices.
- Rounded 12–18px cards with subtle borders instead of glow effects.
- Compact app-style header, search field, genre chips, featured shelf and horizontal book sections.
- Bottom NavigationBar uses Material 3 NavigationBar styling.
- Splash, drawer and profile promo sections use solid surfaces.

## Existing functionality
Firebase authentication, Firestore, Cloudinary image handling, cart, wishlist, profile and admin flows were left intact.
