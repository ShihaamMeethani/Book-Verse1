BookVerse password reset uses Firebase Authentication free built-in email delivery.

Required Firebase Console setting:
Build > Authentication > Sign-in method > Email/Password > Enable.

Then run flutter clean, flutter pub get, flutter run.

The user enters the email used for their BookVerse email/password account. Firebase sends the reset email; the user clicks it and chooses a new password. Google-only accounts do not have a Firebase email/password password to reset.
